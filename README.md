_3replaceGui.py
    
    This is a windowed, user friendly version of the original.
    It finds a specified string in filenames, then replaces all.
    
    User defines:   Parent directory (Search is recursive-only)
                    String to find
                    String to replace with

    Please note:
    Requires _3replace.py be in the same directory as _3replaceGui.py


_3replace.py

    This is the original function for 3replace, where
    the user defines a parent directory, a string to find
    in filenames, and a string to replace with. Function is
    recursive only.  This version uses command line input.
